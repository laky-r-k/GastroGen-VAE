# Synthetic Gastric Cancer Patient Dataset (WGAN-GP)

⚠️ **CRITICAL PROTOCOL RESTRICTION:**
- This synthetic dataset was generated by a Conditional WGAN-GP trained strictly on `dataset/gastric_cancer_train.csv` (569 real patients).
- **It must ONLY EVER be used for TRAINING and AUGMENTATION.**
- **NEVER use this synthetic data for validation, holdout testing, or diagnostic performance evaluation.** All evaluations must be performed strictly on real clinical patient records to avoid catastrophic evaluation bias and data leakage.
